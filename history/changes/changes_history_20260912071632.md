Self-sustained cookie mode completed: a browser-provided cookie (explicit --browser or auto-detection) is now synced automatically to ~/.config/ollama_usage/cookie, so the stored copy stays fresh without manual action; manual steps are only required when no browser is available and the cookie expires (--save-cookie re-run, hinted on auth failures).
