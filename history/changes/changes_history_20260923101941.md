- **20260923101941**: `_build` gained `BUILD_JOBS=<n>` (env) for the Nuitka `--jobs` value. The default is 1 C compiler job — a build must never peg the CPU; a higher value is accepted only on explicit request and is capped at half the logical CPUs (`nproc / 2`), with a printed note when the cap applies. A non-positive-integer value aborts before the build. The help text (`./_build --help`) and the header comment document the variable.
